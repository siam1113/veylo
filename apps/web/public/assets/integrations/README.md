# Integration brand marks

Locally vendored SVG brand marks, rather than letter placeholders or remote image requests.
Trademarks belong to their respective owners; use identifies the connected service.

- Google Calendar, ClickUp, Jira, Trello: SVGs from [Vector Logos](https://github.com/gilbarbara/logos/tree/main/logos), distributed under CC0. Filenames: `google-calendar.svg`, `clickup-icon.svg`, `jira.svg`, `trello.svg`.
- Asana, Notion: [Simple Icons 13.8.0](https://github.com/simple-icons/simple-icons/tree/13.8.0/icons), CC0. Asana uses its brand coral `#F06A6A`.
- Outlook: [Simple Icons 12.0.0](https://github.com/simple-icons/simple-icons/blob/12.0.0/icons/microsoftoutlook.svg), CC0, brand blue `#0078D4`.

These are redistributed brand assets, not endorsements from the providers.

- Todoist, Linear, GitHub, iCloud: Simple Icons 13.8.0 (linked above), CC0; brand colors applied without altering paths.
- Slack: [Vector Logos slack-icon.svg](https://github.com/gilbarbara/logos/blob/main/logos/slack-icon.svg), CC0, original multicolor artwork.
- Microsoft To Do: [Dashboard Icons microsoft-to-do.svg](https://github.com/homarr-labs/dashboard-icons/blob/main/svg/microsoft-to-do.svg), redistributed Microsoft brand mark. See the source project's licensing and Microsoft's trademark terms.
